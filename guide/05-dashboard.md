# 5. 生徒ダッシュボードの準備

[← 目次](README.md)

採点した結果と答案の画像を、生徒が自分の学校の Google アカウントで見られるようにする画面です（Google Apps Script）。使わなくても、採点と返却はできます。

**使えるのは、学校の Google アカウント（Google Workspace）です。** 生徒の本人確認に、学校のドメインのアカウントを使うためです。

## はじめに（1回だけ）

1. [テンプレート](https://script.google.com/d/1PdRwewSt0qlpimL8-A24jZYb9v4UiIPbLGAyC7DDFf2DHmnAwQuvot3l/edit?usp=sharing)を、学校のアカウントで開く
2. 左の ⓘ（概要）→ 右上の「コピーを作成」
3. コピーで「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**（「全員」にはしないでください）
4. 「デプロイ」→ 許可を求められたら、内容を確かめて許可する
   - 「Google で確認されていません」と出たときは、作成者が自分になっているのを確かめて「詳細」から進みます
5. 出てきた URL（`…/exec`）を開くと、先生用の画面が出ます。いちばん下に版の番号が出ます

## テストごとに

1. 採点アプリの「出力」→「ダッシュボード用の ZIP を保存」
2. 先生用の画面で、その ZIP を選ぶ
3. 「この生徒の画面を確認」で、生徒にどう見えるかを確かめる
4. 先生用の画面の「生徒に伝える URL」を、Classroom などで生徒に知らせる
5. 見せる期間が終わったら、そのテストの「公開をやめる」を押す（先生のドライブのごみ箱に移り、30日で消えます）

## 気をつけること

- 答案の画像と結果は、先生のドライブの「採点アプリ_ダッシュボード（生徒と共有しないでください）」フォルダに入ります。**このフォルダは、だれとも共有しないでください**
- 生徒には、本人の結果と答案だけが表示されます。名簿にメールアドレスがない生徒は、結果を見られません

## 新しい版が出たとき

自分のコピーのファイルの中身を、[`dashboard/`](../dashboard) の同じ名前のファイルに貼り替え、「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイします（`Code.js` は、エディタでは `Code.gs` です）。

- 「新しいデプロイ」は作らないでください。生徒に伝えた URL が変わります
- 新しくコピーし直すと、前のテストが見えなくなります
