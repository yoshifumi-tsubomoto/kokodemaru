# 1. はじめに（必要なもの）

[← 目次](README.md)

## 必要なもの

| もの | 説明 |
|---|---|
| 端末 | Windows のパソコン、または Chromebook。Mac でも動きます |
| ブラウザ | **Chrome** か **Edge**。InPrivate・シークレットのウィンドウでは使わないでください（閉じるとデータが消えます） |
| 正答例 | Word などで作った正答例を、**PDF として保存**したもの |
| 白紙の解答用紙（あるとよい） | 正答例と同じ解答用紙の、何も書いていないもの（PDF）。「図1」「①」など印刷された文字を、答えと区別できるようになります |
| 答案のスキャン | 学校の複合機などで、答案をクラスごとに PDF にしたもの |
| 名簿 | Excel の「学年・組・番・氏名・メールアドレス」の列（学年はなくてもよい） |

生徒ダッシュボード（生徒が自分の結果を見る画面）も使うときは、**学校の Google アカウント**が必要です（[5. 生徒ダッシュボードの準備](05-dashboard.md)）。

## 答案のデータはどこに行くか

答案の画像・名簿・採点結果は、**開いている端末のブラウザの中だけ**に保存します。インターネットの向こうのサーバーには送りません。

「AI 読み取り」を有効にしたときだけ、先生が選んだ方法（学校のアカウントの Gemini、または許可を得た Claude API）に、名前などの欄を白く消した解答欄の切り抜きを渡します。使うかどうかは先生が選べます（[3. 初期設定](03-shokisettei.md)）。

学校で使うときは、学校の情報管理のきまりに従ってください。
