# まず試してみる（ダミーのデータ）

[← 目次](README.md)

自分の答案を用意しなくても、ダミーのデータでひととおり試せます。**生徒の名前も答案も、すべて架空のもの**です（手書きふうの書体で作った答案です）。

## 使うファイル

[`samples/`](../samples) から、次のファイルをダウンロードします（ファイルを開いて、右上の「⬇（Download raw file）」）。

| ファイル | 中身 |
|---|---|
| [seitourei.pdf](../samples/seitourei.pdf) | 正答例（中学2年 理科、50問） |
| [kaitouyoushi.pdf](../samples/kaitouyoushi.pdf) | 白紙の解答用紙 |
| [dummy-roster.tsv](../samples/dummy-roster.tsv) | 名簿（架空の10人） |
| [dummy-scan.pdf](../samples/dummy-scan.pdf) | 答案のスキャン（8人分。4番と9番は欠席） |
| [dummy-late.pdf](../samples/dummy-late.pdf) | 遅れて受けた2人（4番・9番）の答案 |

## 試し方

1. **正答例**：`seitourei.pdf` を読み込み、つづけて白紙の解答用紙に `kaitouyoushi.pdf` を読み込む。見つかった解答欄と正答を見てみる
2. **名簿**：`dummy-roster.tsv` をメモ帳か Excel で開き、全部を選んでコピーして貼り付ける。**4番と9番の「欠席」にチェック**を入れる
3. **答案読み込み**：`dummy-scan.pdf` を読み込む。「答案と生徒の対応」で、答案の名前と生徒が合っているか見る
4. **採点**：問題ごとに、似ている答えがまとまって並ぶのを見ながら、〇✕をつけてみる
5. **遅れて受けた生徒**：「答案読み込み」の「遅れて受けた生徒の答案を追加」で `dummy-late.pdf` を読み込む
6. **出力**：Excel や返却用 PDF を保存してみる

試し終わったら、テストの一覧から、そのテストを「消す」で消せます。

くわしい操作は [4. テスト1回分の流れ](04-nagare.md) を見てください。
