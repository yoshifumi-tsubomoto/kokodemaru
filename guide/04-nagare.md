# 4. テスト1回分の流れ

[← 目次](README.md)

画面の上のタブ（正答例 → 名簿 → 答案読み込み → 採点 → 出力）を、左から順に進めます。AI 読み取りを有効にすると「AI読み取り」のタブが加わり、タブの番号が1つずつずれます。各画面の説明は「▼ 操作の説明を表示」でも見られます。

## 正答例

1. 正答例の PDF を読み込む
2. 白紙の解答用紙の PDF もあれば読み込む（印刷された「図1」「①」などを、答えと区別できます）
3. 問題用紙の PDF もあれば読み込む（下の「問題用紙」）
4. 「解析」を押し、見つかった解答欄と正答を確かめ、ずれていれば直す（下の「解答欄の自動読み取りと直し方」）
5. 問題ごとに、配点・観点（知識・技能／思考・判断・表現）・解答の種類（記号・用語・説明・手採点）を確かめる

ブラウザのファイルの欄は、画面を移ると「選択されていません」に戻ります。読み込んだものはテストに覚えてあり、欄の横に「✓ 読み込み済み」と出ます。

### 正答例は、Word などで作って「PDF として保存」したものを使う

| 正答例の作り方 | 読み取りのようす |
|---|---|
| **Word などで作り、「PDF として保存」**（おすすめ） | PDF の中に**文字そのもの**が入っているので、正答の文字をそのまま読めます。罫線もくっきりしていて、解答欄の位置も正確に見つかります |
| 印刷物を**スキャン**したもの | PDF の中身は**画像だけ**です。罫線から解答欄を見つけ、正答は端末の中の小さな AI や、Claude・Gemini で読みます（下の「印刷物しかないテスト」）。読んだ正答は、必ず確かめてください |

自分で作ったテストは、印刷した正答例をスキャンするのではなく、Word のファイルから直接「PDF として保存」（または「エクスポート」→「PDF」）してください。

### 解答欄の自動読み取りと直し方

正答例を読み込むと、次のものを自動で見つけます。

- **解答欄**：外枠と罫線から、欄の位置を見つけます
- **通し番号**：1, 2, 3…と並ぶ番号を、問題の番号にします
- **観点**：通し番号に網掛けがある問題を「思考・判断・表現」、ない問題を「知識・技能」にします
- **正答**：欄の中の文字を正答にします（白紙の解答用紙があれば、印刷済みの「図1」「①」などを除きます）
- **組・番・氏名・点数の欄**：「(組)(番)(氏名)」の括弧の間と、「点」の文字を囲む枠の右隣を見つけます

ずれていたり、見つからなかったりしたときは、画面の上で直せます。

- 枠を**選んで動かす**、辺や角をつかんで**大きさを変える**
- 「**描き直す**」で、枠を描き直す
- 見つからなかった欄（組・番・氏名・点数など）は、クリックして枠を描く
- 正答・配点・観点・解答の種類は、問題ごとに書きかえられる

組・番・氏名の欄の位置は、答案と生徒の対応を確かめるときと、AI に渡す画像から名前を白く消すときに使います。ずれていないか、必ず確かめてください。

### 印刷物しかないテスト（共通テストなど）：スキャンした正答例から始める

正答例が印刷物しかないときは、スキャンした PDF をそのまま「正答例PDF」で読み込めます。

- **スキャンのしかた**：解答用紙の**外枠が全部写るように**スキャンします。横向きに置いても構いません（向きと傾きを自動で直します）。向きが違って見つからないときは「向きを変えて解析し直す」を押します
- **自動で見つけるもの**：解答欄、通し番号（解答欄のすぐ右の細い列）、観点（通し番号を囲む□は「知識・技能」、○は「思考・判断・表現」）、組・番・氏名・点数の欄（表の下の帯）
- **白紙の解答用紙**：スキャンしたものでも、正答例と同じ向き・位置にそろえて使えます
- 図や作図（丸をかくなど）の問題は「手採点」になります

**正答の読み取り**：スキャンした正答例には文字のデータがないので、表の下の「正答をまとめて入れる」で入れます。

| 方法 | 読めるもの |
|---|---|
| 「記号の正答を端末で読む」 | 赤い1文字の記号（ア・イ・A・B など）。端末の中だけで読み、外には送りません |
| 「Claude で正答を読む」（Claude API を使うとき） | すべての問題。読んだ正答は、そのまま表に入ります |
| 「Gemini 用の指示文をコピー」（Gemini を使うとき） | すべての問題。正答例の PDF と一緒に Gemini に渡し、答えを貼り付けます |

- 正答は「番号 正答」の行で、貼り付けて入れることもできます
- **読んだ正答は、必ず正答例と見比べて確かめてください**
- 正答例や問題用紙を AI に送るときは、テストの発行元のきまりも確かめてください

### 問題用紙（任意）

問題用紙を読み込むと、次のことができます。

| | できること |
|---|---|
| AI を使わなくても | 採点の画面で、答案の上に問題文が出ます。「大問 ▼」の札を押すと、大問の初めの実験の説明と、問題文の全文が開きます（Word で作った問題用紙のとき。端末の中だけで読みます） |
| AI を使うと | 説明問題の採点基準づくりと評価で、問題文と大問の前置きも AI に渡し、問われていることに合わせて判断させます |

スキャンした問題用紙は、「AI読み取り」の画面の説明問題のところ（「問題用紙から問題文を読む」）で、Claude または Gemini に読ませます。問題用紙に通し番号がなくても、解答用紙の大問・小問の番号と見比べて番号を決めます。

### 図やグラフの問題：手書きの見本

Word で作った正答例では、グラフや図の欄が白紙のままになり、採点のときに見本がありません。そのときは、手書きの見本を取り込めます。

1. 印刷した解答用紙に、図やグラフの正答を手書きする（1枚にまとめて書けます）
2. 答案と同じように、**外枠が全部写るように**スキャンして PDF にする
3. 「正答例」の画面の「**手書きの見本PDF（任意）**」で、その PDF を選ぶ

- 答案と同じしくみで位置を合わせるので、見本は答案と同じ位置に出ます
- 正答の文字がない問題に、自動で使います。使う問題は、表の「**手書き**」の列で選び直せます
- 使うのは PDF の1ページ目だけです
- やめるときは「手書きの見本を外す」を押します
- 「解析」をやり直すと、見本は外れます。もう一度読み込んでください
- 生徒ダッシュボードで「生徒に正答を見せる」にすると、生徒も見本を見られます（[5. 生徒ダッシュボード](05-dashboard.md)）

## 名簿

1. Excel で「学年・組・番・氏名・メールアドレス」の列を選んでコピーし、貼り付ける（学年の列はなくてもよい。見出しの行は自動で飛ばします）
2. 欠席の生徒にチェックを入れる（スキャンの順番から自動で外します）

メールアドレスは、生徒ダッシュボードを使うときに必要です。

## 答案読み込み

1. クラスごとのスキャンの PDF を読み込む。答案は、そのクラスの出席者に、スキャンした順で割り当てます
2. 「答案と生徒の対応」で、答案の組・番・氏名と、割り当てた生徒が合っているか確かめる

**答案の枚数が出席者の数と合わないときは、画面の上に黄色の知らせが出ます。** 名簿にない生徒（転入生・特別支援学級の生徒など）の答案が混ざっている、または欠席者を名簿で欠席にしていないと、その答案から後ろの割り当てが1人ずつずれます。名簿を直すか、一覧で生徒を選び直してください。
3. 遅れて受けた生徒の答案は、「遅れて受けた生徒の答案を追加」から足せます（今の採点結果はそのまま残ります）

PDF は、その端末の中だけで処理します。

## AI 読み取り（有効にしたときだけ）

[3. 初期設定](03-shokisettei.md) で AI 読み取りを有効にすると出ます。画面の説明に従って読み取らせます。

### 説明問題の採点基準

「説明」の問題は、AI が答案を「採点の要素」に照らして評価し、点数はアプリが計算します。「問題文・採点基準を編集」で、次のように決められます。

| 設定 | 使いどころ |
|---|---|
| 要素と配点 | 「書けていれば〇にする内容」と、その配点。書けている要素の配点を足します |
| 部分点なし | すべての要素が書けているときだけ配点どおり、1つでも欠けていれば0点 |
| 書いていたら0点にする誤り | 理由を取り違えた答え（例：「水が逆流するのを防ぐ」）などは、ほかの要素が書けていても0点 |
| 減点 | 漢字の間違いなど、当てはまれば点を引く（0点より下にはしない） |

- 「よくある減点をまとめて入れる」で、漢字の間違い・「理由を書け」に「〜から」「〜ため」で答えていない、の減点を、当てはまりそうな問題にまとめて入れられます
- 採点基準・問題文を直したあとに「評価を頼む」を押すと、**直した問題の答案だけ**を評価し直します（配点や「部分点なし」だけを変えたときは、評価し直さなくても点数が変わります）
- 用語の問題は、読み取りが正答（または別解）とぴったり同じときだけ〇候補になります。文で答える問題は「説明」にしてください

### 精度と改善

採点が進むと、「精度と改善」に、AI の候補と先生の採点が合った割合が出ます。

- **自信ありの欄の割合**：まとめて採点できる欄がどれだけあるか
- **自信の学習**：用語の問題で、読み取りが正答とぴったり同じだった答案が、AI の自信の段ごとにどれだけ合っていたかを数え、十分に合っている組は自信ありとして扱います。学習で上げた答案はまとめて選ばれますが、自動では採点しません。数えるのは件数だけで、バックアップのファイルで別の端末に移せます。チェックを外すと止められます

## 採点

**問題ごと**に、似ている答えをまとめて並べます。

- まとまりごとに「〇 全員」「✕ 全員」でまとめて採点できます
- 1枚ずつ見るときは、キーボードで採点できます（画面に出るキーの説明を見てください）
- 「採点の段階」（〇候補の確認 → ✕候補の確認 → 外した答案 → 1人ずつ）に沿って進めると、見落としが減ります
- 部分点、コメント、波線などの書き込みもできます
- 「生徒別に採点」で、1人の答案全体を見ながら採点することもできます

### 採点の画面の便利な機能

| 機能 | 使い方 |
|---|---|
| 種類の札 | 「次 ▶」の右に、その問題の採点のしかた（記号・用語・説明・手採点）が出ます |
| 大問の札 | 「大問 ▼」を押すと、大問の前置きと問題文の全文が開きます |
| 大きさ | 「大きさ」で答案を大きくできます（図やグラフの細かい所を見るとき）。ブラウザの拡大（Ctrl＋＋）では、答案は大きくなりません |
| 前の問題へ戻る | 先頭の答案で ← を押すと、前の問題に戻り、最後に採点した答案が選ばれます。最後の答案で → を押すと、次の問題へ進みます |
| 矢印・手書き | 「答案への書き込み」の「矢印」（キー R）と「手書き」（キー P）。返却用 PDF にも入ります |
| スタンプ | 「選択」で書き込みを Shift を押しながらクリックしていくつも選び、「スタンプにする」。一覧から選んで答案をクリックすると、同じ位置に置けます（Shift＋クリックで、クリックした所に置く）。使える範囲（同じ問題・同じテスト・どのテストでも）も選べます |

## 出力

| 出力 | 中身 |
|---|---|
| Excel | 採点結果（点数）・正誤（〇✕△）・設問ごとの平均点と正答率。欠席者の行は空欄で残します |
| 返却用 PDF | 答案に〇✕と点数を書き込んだもの。生徒ごと（ZIP、Classroom で返す用）か、全員分を1つ（印刷用） |
| ダッシュボード用の ZIP | 生徒ダッシュボードに取り込むファイル（[5. 生徒ダッシュボードの準備](05-dashboard.md)） |

ファイルは、その端末のダウンロードフォルダに保存されます。
