# 2. 開く・アプリとして置く

[← 目次](README.md)

## 開く

Chrome か Edge で、次の URL を開きます。ログインはいりません。

https://yoshifumi-tsubomoto.github.io/kokodemaru/

最初に「データと情報管理」の画面が出ます。データの保存場所と、生徒の個人情報を守るための大切なことが書いてあるので、一度読んでください。

## アプリとして置く（おすすめ）

アドレスバーの右の「アプリをインストール」を押すと、ココデマルがアプリとして置かれます。

- ブラウザに採点データを消されにくくなります
- ネットがないときも開けます
- スタートメニューやシェルフ（Chromebook）から開けます

## 新しい版が出たとき

画面に「新しい版があります」と出ます。採点の途中で勝手に変わることはありません。区切りのよいところで切り替えてください。

## 同じ端末・同じブラウザで使う

データは、**端末ごと・ブラウザごと**に別々です。学校の PC で採点した続きを家の PC で開いても出てきません（続けるときは [6. データを守るために](06-data.md) のバックアップを使います）。

同じテストを2つのタブで同時に直さないよう、**タブは1つで**使ってください。
