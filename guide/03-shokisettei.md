# 3. 初期設定

[← 目次](README.md)

画面の右上の「⚙ 初期設定」で変えられます。設定は、その端末だけに保存されます。

## 実名を出す／隠す

| 設定 | 採点の画面での表示 |
|---|---|
| 実名を出す | 「2年1組5番 氏名」のように表示します |
| 実名を隠す | 「受験者 017」のような仮の名前にし、答案に写った組・番・氏名の欄も白く隠します。だれの答案か分からない状態で採点できます |

実名を隠しても、名簿・答案の読み込み・出力の画面では実名のままです。

## AI 読み取り（使うときだけ）

理科の用語や説明の問題を、AI に読み取らせて採点を手伝わせる機能です。**使わなくても採点はできます。** 有効にすると「AI読み取り」のタブが出ます。

| 方法 | しくみ | 費用 |
|---|---|---|
| Gemini（学校のアカウントのチャットに、手で渡す） | 読み取り用の PDF を保存して、学校のアカウントの Gemini に渡し、答えを貼り戻します | かかりません |
| Claude API（自動で読み取る） | 解答欄を自動で送って読み取ります。API キーが必要です | 使った分だけ、キーの持ち主に請求されます。1か月の上限を決められます |

- AI に渡すのは、名前・組・番の欄を白く消した、解答欄の切り抜きだけです
- **使う前に、学校・教育委員会の許可を確かめてください**（Claude API を選ぶと、確認の画面が出ます）
- API キーは、その端末のブラウザの中だけに保存します。「APIキーを消す」で消せます
