# 3. 初期設定

[← 目次](README.md)

画面の右上の「⚙ 初期設定」で変えられます。設定は、その端末だけに保存されます。

## 実名を出す／隠す

| 設定 | 採点の画面での表示 |
|---|---|
| 実名を出す | 「2年1組5番 氏名」のように表示します |
| 実名を隠す | 「受験者 017」のような仮の名前にし、答案に写った組・番・氏名の欄も白く隠します。だれの答案か分からない状態で採点できます |

実名を隠しても、名簿・答案の読み込み・出力の画面では実名のままです。

## AI 読み取り（使うときだけ）

理科の用語や説明の問題を、AI に読み取らせて採点を手伝わせる機能です。**使わなくても採点はできます。** 有効にすると「AI読み取り」のタブが出ます。

| 方法 | しくみ | 費用 |
|---|---|---|
| Gemini（学校のアカウントのチャットに、手で渡す） | 読み取り用の PDF を保存して、学校のアカウントの Gemini に渡し、答えを貼り戻します | 追加の費用はかかりません（学校や自治体が契約している Google のサービスの範囲で使います） |
| Claude API（自動で読み取る）**おすすめ** | 解答欄を自動で送って読み取ります。API キーが必要です | 使った分だけ、キーの持ち主に請求されます。1か月の上限を決められます |

**おすすめは Claude API です。** 理由は次のとおりです。

- 解答欄を1つずつ送るので、番号と画像の取り違えが起きません（Gemini は PDF をまとめて渡すため、取り違えることがあります）
- PDF の保存・ドラッグ・貼り付け・貼り戻しが要らず、自動で読み取ります
- スキャンした正答例の正答も、自動で読めます
- 答案の PDF が、チャットの履歴に残りません（Gemini では、渡したファイルが Gemini 側に残ります）
- 費用の上限を、ココデマルの中と Claude Console の両方で決められます

費用をかけられないときや、Claude API を使う許可が出ないときは、Gemini を使ってください。

- AI に渡すのは、名前・組・番の欄を白く消した、解答欄の切り抜きだけです
- **使う前に、学校・教育委員会の許可を確かめてください**（Claude API を選ぶと、確認の画面が出ます）
- API キーは、その端末のブラウザの中だけに保存します。「APIキーを消す」で消せます

> ⚠ **サービスの決まりは、予告なく変わります。**
> 入力した内容が学習に使われるか、どのくらいの期間残るか、などの扱いは、Google や Anthropic が変えることがあります。この手引きの説明は **2026年11月8日** に確かめた内容です。
> **使い始める前と、年度の初めなどに、必ず**各サービスの最新の説明と、自分のアカウントの設定を確かめてください。分からないときは、学校の管理者に聞いてください。

### 有効にする手順（Gemini・Claude API 共通）

1. 画面の右上の **「⚙ 初期設定」** を押す
2. **「AI 読み取り（理科用語・説明問題の自動採点）」** にチェックを入れる
3. 出てきた **「AI 読み取りの方法」** で、次のどちらかを選ぶ
   - 「Gemini（学校のアカウントのチャットに、手で渡す）」
   - 「Claude API（自動で読み取る）」 … 選ぶと「学校・教育委員会から、Claude API の利用の許可を得ていますか？」と聞かれます。許可を得ているときだけ「OK」を押します
4. **「閉じる」** を押す。画面の上に **「AI読み取り」** のタブが出ます

チェックを外すと、もとの画面に戻ります（読み取った結果は消えません）。

### Gemini を使えるようにする

**準備（1回だけ）**

- 学校のアカウントで Gemini（https://gemini.google.com/app ）が使えるかを確かめます。使えないときは、学校の管理者に聞いてください
- ココデマルを開くブラウザで、学校のアカウントにログインしておきます
- **学習に使われない扱いになっているかを、学校の管理者に確かめます。** Google Workspace の契約の対象になっている学校のアカウントでは、Gemini に渡したファイルやチャットは、人による確認に回されず、モデルの学習にも使われない、とされています。ただし、これは契約の対象のアカウントだけです
- **個人の Google アカウントの Gemini には、答案を渡さないでください。** 個人のアカウントでは、設定によって、入力した内容が学習や人による確認に使われることがあります
- 会話の履歴がどのくらいの期間残るか（学校の管理者が決めます）も、あわせて確かめておきます

**テストごとの使い方**

1. 「AI読み取り」のタブを開く。はじめてのときは **「作業用フォルダを選ぶ」** で、ココデマル専用の空のフォルダを選ぶ（下の「Gemini を使うとき：作業用フォルダ」）
2. **「① まとめて準備」** を押す。指示文がコピーされ、読み取り用PDFが保存されます
3. 表の **「Gemini を開く」** → 保存したPDFを Gemini の画面にドラッグ → 指示文を貼り付け（Ctrl+V）→ 送信。PDFが複数あるときは、PDFごとに別のタブで同時に進められます
4. 答えの最後に「--- おわり ---」が出たら、答えの下のコピーのボタンを押す
5. ココデマルに戻り、**「② 答えを読み込む」** を押す。タブごとに、順番はばらばらでかまいません

### Claude API を使えるようにする

Claude API は、Anthropic という会社のサービスです。使った分の費用が、API キーの持ち主に請求されます。

**準備（1回だけ）：API キーを作る**

1. Claude Console（https://platform.claude.com/ ）でアカウントを作る。学校や自治体で用意してもらえる場合は、そちらを使います
2. 支払いの設定（https://platform.claude.com/settings/billing ）で、画面の案内に従って支払い方法を登録し、利用額を入れる
3. Console で、使う金額の上限を決めておく（ココデマルの上限は、その端末で使った分しか数えられないため）
4. API キーの画面（https://platform.claude.com/settings/keys ）で、キーを作ってコピーする。キーは作ったときにしか表示されないことがあります
5. **学習に使われない設定のままかを確かめる。** Claude API に送った内容は、初期設定では、モデルの学習に使われません。Console の設定で、データを学習に提供する設定をオンにしていないことを確かめてください

**学習に使われることがある場合（避けてください）**

- 自分から「データを学習に使ってよい」を選んだとき
- フィードバックや不具合の報告として、送った内容を Anthropic に送ったとき（答案の画像が入った内容は送らないでください）

画面のメニューの名前は変わることがあります。くわしくは、公式の説明「[Get your Claude API key](https://platform.claude.com/docs/en/get-api-key)」を見てください。

**ココデマルに設定する**

1. 「⚙ 初期設定」で「Claude API（自動で読み取る）」を選ぶ（上の「有効にする手順」）
2. **「モデル」** を選ぶ
3. **「1か月の利用額の上限」** に、円で金額を入れる。上限に達すると読み取りを止めます（0 にすると上限なし。1ドル＝150円の目安で、この端末で使った分だけを数えます）
4. **「APIキー」** の欄に、コピーしたキーを貼り付ける
5. **「接続を確かめる」** を押し、「✔ つながりました」と出れば準備完了です

**API キーの扱い**

- キーは、その端末のそのブラウザの中だけに保存されます（採点データのバックアップにも入りません）
- 共用のパソコンでは使わないでください。使い終わったら **「APIキーを消す」** を押します
- キーは人に渡したり、メール・チャット・ファイルに書いたりしないでください。漏れたかもしれないときは、Console でそのキーを無効にして、作り直してください

### Gemini を使うとき：作業用フォルダ

Gemini に渡す「読み取り用_….pdf」には、生徒の手書きの解答欄が入っています。

- 「AI読み取り」の画面で **「作業用フォルダを選ぶ」** を押し、ココデマル専用の空のフォルダを選んでおくと、PDF をそこに保存し、**答えを読み込み終えた PDF は、ココデマルが消します**（Chrome・Edge・Chromebook）
- ココデマルが消すのは、選んだフォルダの中の「読み取り用_….pdf」だけです。ほかのファイルには触りません
- ブラウザを開き直したあとは、フォルダの使用を許可するか、もう一度聞かれることがあります
- 作業用フォルダを選ばないときは、ダウンロードフォルダに保存します。読み終わったら、ダウンロードフォルダから消してください
- **Gemini に渡したファイルは、Gemini 側に残ります。** ココデマルからは消せません。学校のアカウントの設定（履歴の保存など）を確かめてください
