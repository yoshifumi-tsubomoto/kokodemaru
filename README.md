# ココデマル

**ブラウザで開くだけ。答案は、この端末から出ません。**

中学校の先生のための、テストの採点アプリです。スキャンした答案（PDF）を読み込み、問題ごとに似ている答えをまとめて、〇・×をつけていきます。

## 開く

https://yoshifumi-tsubomoto.github.io/kokodemaru/

- Chrome・Edge で開いてください。Chromebook でも使えます
- 一度開けば、ネットがなくても開けます（ブラウザにアプリをしまいます）

## しくみ

```
GitHub（アプリのプログラムを配るだけ）
   ├─→ A先生のブラウザ：A先生の答案・結果だけ
   └─→ B先生のブラウザ：B先生の答案・結果だけ
```

- URL を開くと、アプリのプログラムだけが届き、**先生のブラウザの中で**動きます。ログインはいりません
- 答案・名簿・採点結果は、**それぞれのブラウザの中に別々に**保存されます。何人が同時に使っても、おたがいのデータは見えず、じゃまし合うこともありません

### よくある質問

- **学校の PC で採点した続きを、家の PC でできますか？**
  データは端末ごとに別です。「データと情報管理」からバックアップを書き出し、もう一方の端末で読み込んでください
- **同じテストを、二人の先生で分けて採点できますか？**
  データは共有されません。分けるときは、バックアップを書き出して渡してください
- **タブを2つ開いてもいいですか？**
  同じテストを2つのタブで同時に直さないよう、**タブは1つで**使ってください
- **新しい版が出たら？**
  画面に知らせが出ます。更新するかは、先生が選べます

## 答案のデータについて

- 答案の画像・名簿・採点結果は、**開いている端末のブラウザの中だけ**に保存します。このページの持ち主を含め、だれかのサーバーに送ることはありません
- 「AI で読み取る」機能を使うときだけ、先生が選んだ方法（学校のアカウントの Gemini、または許可を得た Claude API）に、名前などの欄を白く消した解答欄の切り抜きを渡します。使うかどうかは先生が選べます。API キーは、その端末のブラウザにだけ保存します
- 学校で使うときは、学校の情報管理のきまりに従ってください

## 生徒ダッシュボード（生徒が自分の結果を見る画面）

採点した結果と答案の画像を、生徒が自分の学校の Google アカウントで見られるようにする画面です（Google Apps Script）。先生の Google ドライブに置いて使います。

**使えるのは、学校の Google アカウント（Google Workspace）です。** 生徒の本人確認に、学校のドメインのアカウントを使うためです。

### はじめに（1回だけ）

1. [テンプレート](https://script.google.com/d/1PdRwewSt0qlpimL8-A24jZYb9v4UiIPbLGAyC7DDFf2DHmnAwQuvot3l/edit?usp=sharing)を、学校のアカウントで開く
2. 左の ⓘ（概要）→ 右上の「コピーを作成」
3. コピーで「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**（学校のドメイン）内の全員**（「全員」にはしないでください）
4. 「デプロイ」→ 許可を求められたら、内容を確かめて許可する
   - 「Google で確認されていません」と出たときは、作成者が自分になっているのを確かめて「詳細」から進みます
5. 出てきた URL（`…/exec`）を開くと、先生用の画面が出ます

### テストごとに

1. 採点アプリの「⑤ 出力」→「ダッシュボード用の ZIP を保存」
2. 先生用の画面で、その ZIP を選ぶ
3. 先生用の画面の「生徒に伝える URL」を、Classroom などで生徒に知らせる
4. 見せる期間が終わったら、そのテストの「公開をやめる」を押す

### 気をつけること

- 答案の画像と結果は、先生のドライブの「採点アプリ_ダッシュボード（生徒と共有しないでください）」フォルダに入ります。このフォルダは、だれとも共有しないでください
- **新しい版が出たとき**は、自分のコピーのファイルの中身を、このリポジトリの [`dashboard/`](dashboard) の同じ名前のファイルに貼り替え、「デプロイを管理」→ 鉛筆 →「新バージョン」でデプロイします（`Code.js` はエディタでは `Code.gs` です）。新しくコピーし直すと、前のテストが見えなくなります
- 版の番号は、先生用の画面のいちばん下に出ます
