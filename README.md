# ココデマル

**ブラウザで開くだけ。答案は、この端末から出ません。**

中学校の先生のための、テストの採点アプリです。スキャンした答案（PDF）を読み込み、問題ごとに似ている答えをまとめて、〇・×をつけていきます。

## 開く

https://yoshifumi-tsubomoto.github.io/kokodemaru/

- Chrome・Edge で開いてください。Chromebook でも使えます
- 一度開けば、ネットがなくても開けます（ブラウザにアプリをしまいます）

## 答案のデータについて

- 答案の画像・名簿・採点結果は、**開いている端末のブラウザの中だけ**に保存します。このページの持ち主を含め、だれかのサーバーに送ることはありません
- 「AI で読み取る」機能を使うときだけ、先生が選んだ方法（学校のアカウントの Gemini、または許可を得た Claude API）に、名前などの欄を白く消した解答欄の切り抜きを渡します。使うかどうかは先生が選べます。API キーは、その端末のブラウザにだけ保存します
- 学校で使うときは、学校の情報管理のきまりに従ってください
